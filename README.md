# NoMore — Quit Tracker

A minimalist iOS app that helps you quit bad habits (smoking, drinking, gambling, social media, and more) and track your progress, savings, and motivation in one place.

Built with **SwiftUI** and **SwiftData**.

## ✨ Features

- ⏱ **Live streak tracker** — real-time counter of days, hours, minutes, and seconds since you quit
- 🎯 **Multiple habits** — track more than one addiction at once, pin your main focus
- 🏆 **Milestones** — unlock badges from 1 hour to 10 years clean
- 💰 **Money saved** — see how much you've saved based on your daily spending
- 📓 **Journal** — write private notes to process your thoughts
- 💬 **Motivational quotes** — built-in quote collection + add your own favorites
- 💨 **Craving helper** — a 60-second guided breathing exercise for tough moments
- 🔔 **Daily reminders** — customizable local notifications
- 🌗 **Light & dark themes**

## 🛠 Tech Stack

- SwiftUI
- SwiftData (persistent storage for journal entries, quotes, habit records)
- UserNotifications
- No third-party dependencies

## 📱 Requirements

- iOS 17.6+
- Xcode 26+

## 🚀 Getting Started

1. Clone the repo
2. Open `NoMore.xcodeproj` in Xcode
3. Build and run on a simulator or device
